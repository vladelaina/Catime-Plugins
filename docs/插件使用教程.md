# 插件使用教程 

> 全部插件文件都在`plugins`文件夹下。

1. 下载插件：
   - 选择你需要的插件，下载对应插件的文件。
2. 导入插件：
   - 右键Catime的托盘>`插件`>`打开插件文件夹`
   - 把你下载的`插件文件`拖入打开的`插件文件夹`。
3. 启用插件：
   - 右键Catime的托盘>`插件`，点击选择启用对应的插件。


## 关闭插件

- 重启软件就会关闭插件。且恢复到正常的样式。


## 如何自动启用插件

> 默认情况下，插件不会随着软件的启动而自动启动。需要手动启用插件。
> （这是为了防止插件可能的错误，而导致软件无法启动。）
